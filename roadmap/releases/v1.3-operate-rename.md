# v1.3 — Operate Cluster + Rename

**Worktree:** `../wt-v1.3-operate-rename`
**Branch:** `claude/v1.3-operate-rename`
**Estimated effort:** 2 weeks
**Depends on:** v1.2 merged (manifest-driven sidebar makes adding new pages and a new group a one-line change)

---

## Goal

Fill the four practitioner-runbook gaps the council unanimously flagged (observability, safety, cost, deployment). Rename `approaches.md` → `coding-agents.md`. Introduce two new sidebar groups: **Operate** and **Protocols**.

## Acceptance Criteria

### New pages (each must follow editorial commandments)
- [ ] `content/observability.md` — what to trace, span schemas, OTel-for-LLMs, eval-in-the-loop, decision matrix at the end.
- [ ] `content/safety.md` — prompt-injection threat model, tool-misuse, guardrail placement, attack surface, decision matrix.
- [ ] `content/cost-economics.md` — token math, cache economics, hybrid-model routing math, idle-cost calculations, cost-per-PR framing, decision matrix.
- [ ] `content/deployment.md` — shadow → canary → autonomous, SLOs, kill-switches, drift monitoring, decision matrix.

Each new page ends in a "When to use / when not to" decision block, every load-bearing claim cites a primary source, and the frontmatter (or top comment) carries `lastVerified: YYYY-MM-DD` and `staleBy: YYYY-MM-DD`.

### Rename / split
- [ ] `content/approaches.md` renamed to `content/coding-agents.md`. Git move preserved in history.
- [ ] `js/main.js` (or v1.4 router) emits a hash redirect `#approaches` → `/coding-agents/`.
- [ ] Long tail of coding-agent systems demoted to a one-line directory at the bottom of `coding-agents.md`. Top 8 keep full sections.
- [ ] (Optional, defer if scope creeps) `content/coding-clis.md` split from the CLI subsection.

### IA changes
- [ ] `content/manifest.json` adds new group **Operate** containing the 4 new pages.
- [ ] `content/manifest.json` adds new group **Protocols** containing existing MCP/A2UI/AG-UI/identity content (promoted from `infrastructure.md` subsections — either as separate pages or as `infrastructure.md` anchor entries).
- [ ] Sidebar reflects the new groups; "Approaches" entry replaced by "Coding Agents".

### Editorial
- [ ] PM #5's five commandments documented in `CONTRIBUTING.md` (or top of `ROADMAP-V2.md` if v1.4 hasn't shipped CONTRIBUTING yet).
- [ ] Spot-check 3 existing pages and add `lastVerified` dates.
